## Rules

- Only real photographs from the event, supplied by Muhammed. No generated, composited or stock images.
- Send the highest-resolution original available. Phone originals are ideal. The two current files are 582×805 and 722×732, which only supports small display sizes.
- For press coverage, include the publication date, the page or URL, and a full-page scan or link so the claim can be verified.
- The build pipeline (Phase 5) generates resized AVIF/WebP versions and strips all metadata, including GPS location.
- Nothing in a photo or certificate becomes a public claim unless it is also approved in `docs/CONTENT_APPROVAL.md`.
